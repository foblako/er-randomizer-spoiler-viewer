# Elden Ring Randomizer — Spoiler Log Viewer

A blazing-fast, modern desktop GUI for browsing spoiler logs generated by the [Elden Ring Item and Enemy Randomizer](https://www.nexusmods.com/eldenring/mods/428). Built with **Rust + Tauri + React + TypeScript + Tailwind CSS** with virtualized scrolling for instant 144 FPS browsing across 30,000+ entries.

## Features

- **Blazing-fast Rust Core**: Parses massive 5 MB logs (~25 000–30 000 lines) in milliseconds
- **Virtual Scrolling (TanStack Virtual)**: Silky smooth 144 FPS list scrolling without freezing or lag
- **Crystal-clear Boss & Item Cards**:
  - Highlights who you encounter, the exact arena location, and which vanilla boss they replace
  - Location icons, drop sources, runes cost, and replaces information
- **Zero Scroll Jumping**: Checking/unchecking items preserves exact scroll position
- **Built-in Filters**:
  - Great Runes + Access Keys (Raya Lucaria, Volcano Manor, Dectus, Rold, Haligtree, etc.)
  - Boss Remembrances
  - Achievement Bosses (sorted in canonical story progression order)
  - All Bosses / Arenas (218 boss arena slots)
  - Basic & Unique Mobs (Mini Midra, Hornsent Inquisitors, Fire Knights, open-world mobs)
  - All Items (~5,000 generated items)
  - Everything (30,000+ entries)
- **Shopping Cart & User Presets**: Tick items across seeds and save named builds/routes (persisted to `~/.er_randomizer.json`)
- **Real-time Fuzzy Search**: Instant substring search across items, locations, descriptions, and replacement names
- **Dark Fantasy UI**: Elden Ring aesthetic with tarnished gold accents and glowing typography
- **One-click Export**: Copy visible entries to clipboard or save as text file

## Running the App

### Option 1: Tauri + Rust (Modern App)

#### Development mode:
```bash
npm install
npm run tauri dev
```

#### Production build:
```bash
npm run tauri build
```
The compiled standalone `.exe` and installers will be in `src-tauri/target/release/bundle/`.

---

### Option 2: Python / Tkinter (Legacy Version)

```bash
python -m er_randomizer
# or
python er_randomizer_viewer.py
```

## Installing as a package

```bash
pip install -e .
er-spoiler-viewer
```

## Project layout

```
src/                   — Modern React 19 + TypeScript + Tailwind UI
  components/          — Virtualized ResultsView, Sidebar, Header, ItemIcon
  types.ts             — Filters, labels, boss orders, TypeScript interfaces
src-tauri/             — Rust Tauri v2 core
  src/parser.rs        — High-performance spoiler log parser
  src/config.rs        — ~/.er_randomizer.json preset management
  src/models.rs        — Data models (SpoilerEntry, PlacementEntry, etc.)
  tauri.conf.json      — Tauri configuration
er_randomizer/         — Legacy Python Tkinter application
samples/               — Example spoiler logs for testing
```
